# 挑漏探针库

Phase 3–5 的干活手册。费曼学习法值钱的地方在**检出 gap**，不在讲解质量。下面把检测器、探针、判分标准，以及哪些事不能做，一条条写清楚。

## 第一条：教练阶段不给答案

Phase 3（复述）、Phase 4（挑漏）、Phase 5（回源）期间，不透露正确答案。给出答案就等于结束了学习，而用户会以为自己懂了。

允许：

- 说出 gap 的类型（「这里你跳了一步」），不说出缺的内容
- 提一个更精确的追问
- 给回源坐标：`file:line` / 论文 §/页 / `URL#anchor`
- 给一个**同类型但不同实例**的练习题

禁止：

- 复述正确答案，或把它拆成几段「提示」分次喂出去
- 用反问暗示答案（「是不是因为缓冲区满了呢？」）
- 用户卡住三次后心软给答案（见下方「卡死处理」）
- 把「用户点头 / 说『对对对』」当作通过

**卡死处理（窄带重讲）**：同一概念连续 3 次探针都无进展时，不要给答案。退回 Phase 2，只重讲卡住的那一个子步骤（宽度严格限制在该步，不是重讲整章），然后立刻回 Phase 3 让用户重新复述该步。若窄带重讲两轮仍失败，说明前置概念缺失——回 Phase 0 补一个前置概念。

## 通过判据：四道门

一个概念算通过，当且仅当用户在闭卷状态下做到全部四条：

| 门 | 判据 | 违规示例 |
|---|---|---|
| G1 无术语复述 | 用领域外词汇说清「它是什么」 | 用术语解释术语 |
| G2 机制链 | 给出 A→B→C 因果链，每步都有**主语和动作** | 「然后就自动同步了」 |
| G3 边界 | 说出至少一个失效场景 **和** 一个代价 | 只讲优点 |
| G4 反例存活 | 面对一个具体反例或替代设计的追问，不崩溃、能自我修正 | 一被质疑就全盘改口或卡死 |

**四门结论要写成 `gates: {G1, G2, G3, G4}` 布尔落进 `results/sN.json`**，脚本校验 `gates` 与 `score` 是否自洽，不一致就报错。理由是可复核：「整体感觉他懂了」无法复核，逐门结论可以。

判分映射（写入 `results/sN.json` 的 `score`）：

- `score 2` — G1–G4 全过（`gates` 四门全 `true`）
- `score 1` — 过 G1+G2，缺 G3 或 G4（懂机制但不知边界）→ `severity: 重要`
- `score 0` — 缺 G1 或 G2（机制链本身断裂）→ `severity: 致命`

**severity 不能自选。** 它决定 mastery 是否被封顶 0.4；标轻就绕过了 Phase 5 的出口条件，脚本会拦下这种组合。

例外：纯记忆型的 `事实错误` 若不污染机制链，`score 0` 可降为 `重要`，需在 `note` 里写明不污染机制链的理由。

## 九个检测器

每个检测器给出：识别信号 → 探针 → 严重度默认值。探针按顺序试，第一个奏效即停。

### 1. 术语遮蔽

用术语解释术语，或换同义词而不给机制。

信号：定义里出现被定义词本身或其同义词；「就是一种 XX 机制」；把缩写展开当作解释；整段话删掉专业名词后不剩信息。

探针：

- 「把这句话里所有专业名词换成 12 岁能懂的词，再说一遍。」
- 「『X』在这里做的具体动作是什么？主语是谁？」
- 「禁用 A、B、C 这三个词，你怎么讲？」

严重度：重要。若某个核心概念**完全**靠术语支撑 → 致命。

### 2. 跳步

两个状态之间用连接词糊过去，因果链断裂。

信号：「然后就…」「自然就…」「于是系统就…」；一步跨越多个抽象层；被问到中间步骤时说「这块是框架做的」。

探针：

- 「从 X 到 Y 之间到底发生了什么？逐步说，每步给主语和动作。」
- 「为什么不能直接从 X 到 Z？中间少那步会怎样？」
- 「把这一步再拆成三步。」

严重度：致命（机制链断裂等于没懂机制）。

### 3. 伪因果

把相关或时序当因果，倒果为因，或把概率性行为说成必然。

信号：「因为 A 之后发生了 B」；「为了避免 X 所以设计了 Y」（但 Y 实际是为 Z）；用「保证 / 一定 / 必然」描述概率性行为；无法回答「移除 A 会怎样」。

探针：

- 「只保留 A、移除其他条件，B 还会发生吗？」
- 「这个设计真正要解决的问题是什么？有没有更直接的原因？」
- 「你说『为了避免 X』——源材料里哪一句支持这个动机？」

严重度：致命。

### 4. 边界失守

说不出何时失效、代价是什么。

信号：全是优点没有代价；「总是 / 永远 / 任何情况下」；举不出反例；把适用条件当普适规律。

探针：

- 「什么输入会让它变慢、出错、或完全不适用？」
- 「它换来了什么代价？牺牲了哪个性质？」
- 「规模 ×1000、并发 ×100 会怎样？」
- 「什么情况下你会**不**选它？」

严重度：重要。核心机制的边界 → 致命。

### 5. 类比反噬

类比携带了本体没有的属性，或掩盖了关键差异。

信号：用类比代替机制（被追问就只会重复类比）；类比在关键维度失真（「缓存就像字典」——忽略了失效与容量）。

探针：

- 「这个类比在哪一点上是**错**的？」
- 「如果我把你的类比当真理，我会推出什么错误结论？」
- 「把类比里对应不上的部分列出来。」

严重度：细节。若类比是其理解的唯一支柱 → 重要。

### 6. 鹦鹉学舌

复述源材料的顺序与措辞，而非重构知识。

信号：与原文语序、用词高度重合；打乱提问顺序后答不上；只能整体背诵、不能局部展开；被问「为什么」时回到「文档就是这么写的」。

探针（重点：**打乱顺序**，背诵失效）：

- 「从结果倒推原因，重讲一遍。」
- 「只准用 3 句话，讲给完全没背景的人。」
- 「为什么不用 <另一种常见设计>？」（问一个源材料没比较过的替代方案）
- 从材料的**末尾**章节开始提问。

严重度：重要。

### 7. 粒度错配

用 what 回答 why，或用宏观回答微观（反之亦然）。

信号：问机制答功能；问接口答实现；问设计动机答 API 用法；问「为什么」答「是什么」。

探针：

- 「我问的是 why，你答的是 what。为什么是这样而不是别的方式？」
- 「镜头拉近一层再说一遍。」/「推远一层，这在整体里解决什么？」

严重度：细节。持续错配（同一概念两次以上）→ 重要。

### 8. 事实错误

与已验证信源冲突的具体断言。

信号：数字、名称、顺序、默认值错；把 A 的行为安到 B 上；把旧版本行为当现状。

**处理特例**：这是唯一允许立刻直接纠正的检测器——它是记忆问题，不是理解问题，苏格拉底式追问只会浪费时间。但纠正后要追问一句「你为什么会记成这样」：错误的记忆几乎总是指向一个错误的心智模型，那才是真 gap。

严重度：视污染范围。若导致后续推理整体失效 → 致命。

### 9. 未验证

断言无信源支撑，或把推测当事实。**这一条同样约束 AI 自己的讲解。**

信号：用户说「应该是」「我记得」「一般来说」；AI 讲解中出现 `sources.md` 未登记的断言；引用的 URL/文件从未实际抓取。

探针：

- 「这一点在源材料的哪里？」
- 若源材料里找不到 → 明确标为**未知**，登记进 `sources.md`。

严重度：重要。若整段推理建立在未验证断言上 → 致命。

## 探针升级阶梯

一次只升一级。用户答不出就停在当前级并记录 gap，不要连跳三级。

| 级 | 名称 | 问法 | 何时用 |
|---|---|---|---|
| L0 | 自由复述 | 「不看材料，把这个讲一遍」 | 每轮开场，基线暴露 |
| L1 | 澄清 | 「你刚说的 X 具体指什么动作？」 | L0 出现模糊处 |
| L2 | 换表征 | 「画出来」/「只准 3 句话」/「倒着讲」 | 疑鹦鹉学舌或术语遮蔽 |
| L3 | 反事实 | 「去掉这步会怎样？」/「为什么不用另一种设计？」 | 疑伪因果 |
| L4 | 边界 | 「什么时候失效？代价是什么？」 | G3 未验 |
| L5 | 迁移 | 「换到 <新场景> 下它怎么变？」 | 仅 L0–L4 全过后 |

## 提问纪律

- **一次一个问题**。一次抛五个，用户会挑最容易的答，gap 被掩盖。
- **先沉默再追问**。L0 之后不要立刻补充引导，让他把话说完——最值钱的 gap 出现在复述的后半段。
- **不打断**。中途纠正会把复述变成对话，失去诊断价值。
- **记录原话**。gap 的 `note` 字段要摘用户原话的关键片段，不要写成「理解不足」这类空泛结论。
- **不放水**。`score 2` 必须四门全过。为了鼓励而给通过，会让 mastery 与 SM-2 排期全部失真，且无法回退。
- **不表扬代替诊断**。「很好」不是反馈；「G2 过了，G3 缺一个失效场景」才是。

## AI 自检：讲解阶段用同一套检测器审自己

Phase 2 讲完、交付给用户之前，逐条自查：

1. G1 — 我有没有用术语解释术语？
2. G2 — 我写的每个「因此 / 所以」，前提是否真的蕴含结论？有没有我自己也在跳步？
3. G3 — 我是否给出了代价与失效条件？（只讲优点的讲解是最常见的失败模式）
4. 检测器 5 — 我的类比在哪里失真？必须**主动声明**失效点，例如「这个类比在 X 处不成立」。
5. 检测器 9 — 每一句断言是否都能在 `sources.md` 找到登记项？找不到的，用自然语言点明是推断或未知，不要当事实讲。
6. 我有没有夹带未经抓取的记忆？（见 `sources.md` 的实抓规则）

自检未过就先修讲解，不要推进到 Phase 3——用户会完整继承你讲解里的每一个 gap，而且因为是你说的，他不会怀疑。
